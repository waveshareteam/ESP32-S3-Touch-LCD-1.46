# ESP32-S3-Touch-LCD-1.46-Test

[简体中文](README_ZH.md)

## Features

Demonstrates the LVGL interface and onboard peripherals.

## Hardware Requirements

Development board and a USB data cable.

## How to Run

`idf.py set-target esp32s3` + `idf.py flash monitor`

## Expected Results

The display shows device status and can switch to the music player.
