# LVGL_Arduino

[简体中文](README_ZH.md)

## Features

Demonstrates the LVGL interface and onboard peripherals.

## Hardware Requirements

Development board and a USB data cable.

## How to Run

Install the bundled libraries from `../../libraries` in the Arduino sketchbook, apply the [board settings](../../../../docs/images/ESP32-S3-Touch-LCD-1.46-arduino-settings.webp), and upload.

## Expected Results

The display shows device status and can switch to the music player.
